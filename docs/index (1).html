Wild Facts Daily Automation

This is a personal automation project that researches, scripts, narrates, edits, and publishes short educational/entertainment videos to the Wild Facts Daily YouTube channel (@WildFactsDailyTV).

The App uses the YouTube Data API to upload videos and thumbnails to this single, developer-owned channel, and the YouTube Analytics API to read aggregate performance statistics for those uploads, in order to improve future content decisions.

See our Privacy Policy for details on data usage.
