Wild Facts Daily Automation

A personal video-publishing automation tool

What this application does

Wild Facts Daily Automation is a personal software project built and operated by a single developer. It automatically researches interesting facts, writes short video scripts, generates narration and visuals, and publishes the finished videos to one YouTube channel that the developer owns: Wild Facts Daily (@WildFactsDailyTV).

Why it requests Google/YouTube access

This application uses the YouTube Data API and YouTube Analytics API, authorized only by the developer's own Google account, to:

  • Upload videos (with title, description, tags, and thumbnail) to the Wild Facts Daily channel.
  • Read aggregate performance statistics (views, watch time, likes) for videos it has uploaded, so future videos can be improved.

It does not request or access any data belonging to any other user or channel.
